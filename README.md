# OpenClicker

OpenClicker is a free and open-source autoclicker for Windows.

No subscriptions. No paywalls. No locked features. No donations required.

## Features

- Left and right mouse clicking
- Customizable click interval
- Custom toggle hotkey
- Multiple built-in themes
- Automatic updates
- Single-file Windows executable
- Self-contained application
- Open source

## Themes

OpenClicker currently includes:

- Neon
- Gold
- White
- Crimson
- Violet
- Arctic
- Secret

## Automatic Updates

OpenClicker includes a built-in update system.

When a newer version is available, the application can detect it and download the latest release directly from GitHub. The update process is handled inside OpenClicker, so there is no separate updater application that needs to be installed.

## Download

Download the latest version from the Releases page:

`OpenClicker-Windows-x64.exe`

Open the executable and OpenClicker will start. No installer or additional runtime installation is required.

## Requirements

- Windows 10 or newer
- 64-bit Windows
